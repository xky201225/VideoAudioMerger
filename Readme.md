无损音视频合并工具

一、启动
双击 run.bat。程序会自动打开浏览器。
如果浏览器没有自动打开，请手动访问：
http://127.0.0.1:8765
（如果 8765 端口被占用，程序会自动选择后续端口，请以启动窗口显示为准。）

二、使用方法
1. 选择或拖入视频文件。
2. 选择或拖入音频文件。
3. 选择输出格式，默认推荐“自动选择”。
4. 点击“开始合并”，等待完成后点击“下载文件”。

三、无损说明
合并使用 FFmpeg 的“copy stream”封装方式，只重新封装容器，
不重新编码视频或音频，因此画质和音质没有任何损失。

四、格式建议
如果提示容器与编码不兼容，请改用“自动选择”或 MKV。
MKV 对常见音视频编码的兼容性最好。

五、支持格式
视频输入：MP4、MOV、MKV、AVI、WebM、M4V、M4S、TS、M2TS、FLV、WMV、MPG、3GP。
音频输入：MP3、AAC、M4A、M4S、WAV、FLAC、OGG、Opus、WMA、AIFF、ALAC、AC3、MKA。
其中 M4S 是 MPEG-DASH 分片文件，可分别作为视频输入或音频输入使用。

六、文件位置
合并结果保存在 outputs 文件夹中，网页下载和该文件夹中的文件一致。
temp 文件夹用于临时上传，可随时清空。
ffmpeg.exe 是便携版 FFmpeg，请勿删除。
